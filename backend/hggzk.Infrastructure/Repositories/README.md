# Repositories Layout

This folder is organized by feature area only. Existing namespaces and class names are unchanged.

- `Base`: shared repository base types
- `Bookings`: booking and reservation-related repositories
- `Properties`: property, section, review, amenity, and related repositories
- `Units`: unit and unit-type repositories
- `Users`: user, role, staff, and account repositories
- `Chat`: messaging and conversation repositories
- `Finance`: currency, chart of accounts, and transaction repositories
- `Notifications`: notification repositories
- `Search`: search and filtering repositories
- `Admin`: general admin/configuration repositories
